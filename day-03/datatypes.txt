DATA TYPES
1.NUMERIC DATA TYPES=> INT(NUMBERS WITHOUT DECIMAL),FLOAT(DECIMAL POINT),COMPLEX(IMAGINARY VALUE)
INTEGER REAL WORLD EXAMPLE => INSTAGRAM(NUMBER OF VIEWS,LIKES,SHARE,POST)
FLOAT REAL WORLD EXAMPLE=> PRICES, DISCOUNT, SALARY
COMPLEX REAL WORLD EXAMPLE => DEALING WITH IMAGE PROCESSING , ALGORITHMS 

2.SEQUENTIAL DATA TYPES=>STR(COLLECTIONS OF CHARACTERS ENCLOSED WITH SINGLE OR DOUBLE QUOTES, 
                           PROPERTIES: immutable=cant be changed in object reference ,ALLOW DUPLICATES,ORDERED,HETEROGENOUS)
                         LIST(COLLECTIONS OF ELEMENTS ENCLOSED WITH THE SQUARE BRACES[],
                           PROPERTIES: MUTABLE, consist of duplicates, DYNAMICALLY SIZED,HETEROGENOUS,LIST IS ORDERD)
                           REAL WORLD EXAMPLE => INSTAGRAM(POST(CAN POST OR DELETE),STORIES)
                         TUPLE(COLLECTIONS OF ELEMENTS ENCLOSED WITH THE PARANTHESIS()
                           PROPERTIES: IMMUTABLE,CONSIST OF DUPLICATES,FIXED SIZED,ITS ORDERD,HETEROGENOUS)
                           REAL WORLD EXAMPLE => GOOGLE MAPS(LIKE X AND Y AXICS)

3.MAPPING DATA TYPES=>SET(COLLECTIONS OF ELEMENTS ENCLOSED WITH THE CURLY BRACES
                            PROPERTIES: MUTABLE,DOESNT ALLOW ANY DUPLICATES,DYNAMICALLY SIZED,HETEROGENOUS,UNORDERD)
                            REAL WORLD EXAMPLE => FOLLOWERS OF INSTAGRAM
                      DICTONARY(COLLECTIONS OF KEY VALUE PAIRS ENCLOSED WITH CURLY BRACES{}
                            PROPERTIES:MUTABLE,ORDERD,HETROGENOUS,DYNAMICALLY SIZED,ALLOWS DUPLICATES)
                      
SET - FROZEN SET(FIXED DATA PROPERTIES: IMMUTABLE,DOESNT ALLOW ANY DUPLICATES,FIXED SIZED,HETEROGENOUS,UNORDERD)

4.BOOLEAN DATA TYPE=>EITHER TRUE OR FALES VALUE

5.NONE DATA TYPE=> USED WHEN THE DATA IS UNSURE AND HELPS TO CREATE AN EMPTY

TYPE CONVERSION
WE CAN CONVERT INTEGER TO FLOAT,BOOL,STR,COMPLEX (CANT CONVERT TO LIST SET DICT TUPLE )
WE CAN CONVERT FLOAT TO INT,BOOL,STR,COMPLEX (CANT CONVERT TO LIST SET DICT TUPLE )
WE CAN CONVERT COMPLEX TO BOOL,STR(CANT CONVERT TO LIST SET DICT TUPLE FLOAT INT )
WE CAN CONVERT STRING(WHICH IS IN NUMBER) TO FLOAT,BOOLEAN,STRING,COMPLEX,LIST,SET,TUPLE (CANT CONVERT INTO DICT) 
WE CAN CONVERT LIST TO STR,BOOL,TUPLE,SET(CANT COVERT INTO DICT)
WE CAN CONVERT TUPLE TO LIST,STR,BOOL,SET(CANT COVERT INTO DICT)
WE CAN CONVERT SET TO STR,BOOL,TUPLE,LIST(CANT COVERT INTO DICT)
WE CAN CONVERT DICT TO STR,BOOL,TUPLE,LIST,SET
WE CAN CONVERT BOOLEAN TO INT,FLOAT,STR,COMPLEX(CANT CONVERT TO LIST SET DICT TUPLE )

list ,set, dict => mutable data types
